如果測試後確認要正式導入，整套系統導入費用是 **NT$58,000**。

這個費用包含：

- 員工 App
- 管理後台
- 後端 API 與資料庫
- 正式環境部署與操作協助
- 導入確認後，正式上線前修正測試回報的規則與問題

這個費用不是單純購買一個打卡工具，而是包含 App、管理後台、後端資料庫、簽核流程、報表、彈性工時規則、上架設定與首年維護。
