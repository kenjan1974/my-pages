CREATE GPT 02 / 07
建立 GPT

從 GPTs 區域建立

操作路徑

  1. ChatGPT → Explore GPTs
  2. 選擇 Create
  3. 用對話建立，或直接進入設定頁編輯

使用限制

建立與編輯目前限網頁版；建立 GPT 需要付費方案，或工作區授權。

CONFIGURATION 03 / 07
設定 GPT

先填基本欄位

名稱

活動宣傳文案助手

說明

貼上企劃案，自動產出三種宣傳文字。

開場提示

請根據以下企劃案產出宣傳文字。

關鍵：真正的規則要放在 Instructions，不要只寫在名稱或說明裡。

INSTRUCTIONS PROMPT 04 / 07
Instructions 範例

把固定規則寫進 GPT

你是「活動宣傳文案助手」。 當使用者貼上活動企劃案時，請自動產出三種宣傳文字： 1. Instagram 貼文：語氣活潑，150 字以內 2. Email 通知：語氣正式清楚，250 字以內 3. 系辦公告：語氣簡潔，條列式 每種版本都必須包含： - 活動亮點 - 適合對象 - 報名呼籲 若企劃案缺少時間、地點、報名方式等關鍵資訊，請標示【需要補充】，不要自行編造。
KNOWLEDGE / CAPABILITIES 05 / 07
可加入的能力

先做好 Instructions，
再決定要不要加工具

Knowledge

上傳過往活動文案、品牌語氣指南、常用格式。

Capabilities

視需要開啟搜尋、圖片生成、Canvas 或資料分析。

Actions

進階可串接外部 API；但 apps 和 actions 不能同時使用。

USE GPT 06 / 07
使用方式

開啟 GPT，貼上新企劃案

以下是我們系上的期末成果展企劃案，請幫我產出三種宣傳文字： 活動名稱：2025 資管系期末成果展 時間：6 月 20 日 14:00-17:00 地點：電腦教室 B201 內容：學生專題展示、業界評審回饋、最佳專題頒獎 對象：在校師生、系友、對資訊科技有興趣的高中生 報名：表單連結 forms.gle/xxx

也可以在一般 ChatGPT 對話中輸入 @ 呼叫 GPT，讓下一則訊息交給它處理。

SHARE / MANAGE 07 / 07
分享與管理

把一次性 Prompt
變成可重複使用的 GPT

分享層級

可依方案與工作區設定，選擇私人、連結分享、工作區分享或發布到 GPT Store。

權限層級

可設定能聊天、能檢視設定、能編輯。公開連結與 GPT Store 通常只支援聊天。

一句話結論：把一次性的 Prompt 變成可重複使用的 GPT，讓每份企劃案都能一鍵產出標準化宣傳內容。
