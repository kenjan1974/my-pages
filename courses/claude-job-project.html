PROJECT DESIGN 02 / 09
先規劃，不急著建立

兩層分工：
Project 放資料，Skill 放流程

Project

放履歷素材庫、作品、職涯偏好，保存「我是誰」。

Skill

放公司研究、素材比對、三角審查、面試題流程。

每次使用

貼公司資料與職缺，讓 Project 呼叫 Skill 跑固定流程。

原則：不要把所有規則都塞進一次對話。個人資料放 Project；重複步驟做成 Skill。

CREATE PROJECT 03 / 09
建立 Project

Claude Projects：求職準備

Project 名稱

求職準備

名稱要讓你一眼知道用途，不要叫「AI 助理」。

放入 Project knowledge

  1. 履歷素材庫
  2. 作品集 / GitHub / 專題連結
  3. 常用自我介紹與經歷摘要
  4. 想投的職務方向與偏好

注意：公司資料與職缺通常每次都不同，不建議長期放進 Project；每次使用時貼到對話即可。

PROJECT INSTRUCTIONS 04 / 09
Instructions

貼進 Project 的固定指令

你是我的求職教練。你的任務不是直接美化履歷，而是協助我用固定工作流準備求職。 Project knowledge 中包含我的履歷素材庫、作品、證照、專案與職涯偏好。 如果可以使用 job-search-coach Skill，請優先依照該 Skill 的流程執行。 每次我貼上公司資料與職缺說明時，請協助我完成： 1. 公司與職缺上下文整理 2. 職缺需求與我的素材庫比對 3. 履歷重點調整建議 4. HR、用人主管、面試官三角審查 5. 面試題與回答練習方向 限制條件： - 不要編造我沒有提供的經歷、數字、證照或成果 - 缺資料時標示【需要補充】 - 招募條件、公司資訊、數字資料要提醒我回到官方來源確認 - 回答要具體、可執行，避免只給空泛建議
SKILL DESIGN 05 / 09
Skill 規劃

Skill 放固定流程：
job-search-coach

--- name: job-search-coach description: 當使用者提供公司資料、職缺說明或履歷草稿，需要進行求職準備、履歷重點調整、三角審查或面試題演練時使用。此 Skill 會使用 Project knowledge 中的履歷素材庫進行比對。 --- # job-search-coach ## 執行步驟 1. 閱讀使用者提供的公司資料與職缺說明 2. 整理公司與職缺上下文，標示需要查證的資訊 3. 從 Project knowledge 的履歷素材庫中找出可對應的經驗、能力與成果 4. 提出履歷重點調整建議，但不要編造不存在的經歷或數字 5. 以 HR、用人主管、面試官三種角色審查履歷或回答 6. 產出可能面試題，並提示應使用素材庫中的哪段經驗回答 ## 輸出格式 - 公司與職缺摘要 - 職缺重視能力 - 可凸顯素材 - 履歷修改建議 - 三角審查表 - 面試題與回答方向
MATERIALS PROMPT 06 / 09
先建立素材庫

Project 需要材料：
先讓 Claude 訪談你

我想建立「履歷素材庫」，但還沒有整理完整。 請扮演求職教練，透過提問協助我整理。 一次只問 3 到 5 個問題，問題要具體、容易回答。 請依序收集： 1. 基本背景：科系、學歷、語言、工具、證照 2. 想應徵的職務與原因 3. 課程專案、社團、實習、打工或競賽經驗 4. 每段經驗中我負責什麼、解決什麼問題 5. 可量化成果：人數、金額、成長率、完成時間 6. 可以連結到職缺的能力或個人特質 訪談結束後，請整理成「履歷素材庫」表格。
USE PROJECT 07 / 09
使用方式

每投一家公司，
就用 Skill 跑一次流程

/job-search-coach 我想應徵以下公司與職缺。 請使用 Project knowledge 中的履歷素材庫，幫我跑完整求職準備工作流。 請輸出： 1. 公司與職缺上下文摘要 2. 職缺最重視的能力與條件 3. 我的素材庫中最適合凸顯的 3 到 5 個經驗 4. 履歷應該優先調整的重點 5. 需要補充或查證的資訊 6. 下一版履歷的建議段落大綱 公司資料：【貼上官網、徵才頁、公司介紹】 職缺說明：【貼上職缺內容】
REVIEW LOOP 08 / 09
三角審查 + 面試演練

讓 Project + Skill
幫你挑問題

/job-search-coach 請根據這份職缺、公司上下文與我的履歷草稿，進行三角審查。 請分別扮演： 1. HR：格式是否清楚、是否符合基本條件、是否容易篩選 2. 用人主管：是否看得出能上手、是否有實際成果 3. 面試官：哪些地方需要追問、哪些描述太空泛 請用表格輸出： 角色 · 看到的亮點 · 主要疑慮 · 建議修改 · 可能追問 最後請列出 5 題最可能被問的面試題，並提示我回答時應該使用素材庫中的哪段經驗。
