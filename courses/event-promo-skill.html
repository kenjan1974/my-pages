WHY SKILL 02 / 07
判斷邏輯

什麼時候值得做成 Skill？

流程固定

每次都要讀企劃，拆成三種宣傳文字。

格式固定

Instagram、Email、系辦公告都有明確限制。

檢查標準固定

每種版本都要包含活動亮點、適合對象、報名呼籲。

一句話：不是把單次 Prompt 存起來，而是把「流程 + 標準」包成一個可重複使用的助理能力。

CREATE ZIP · PROMPT 03 / 07
生成 Skill zip

先請 AI 建立 Skill 檔案

請幫我建立一個 Claude Skill 的資料夾結構並打包成 zip 檔供下載。 Skill 名稱：event-promo 用途：根據活動企劃案，自動產出三種版本的宣傳文字 （Instagram 貼文、Email 通知、系辦公告） 請建立以下檔案結構： event-promo/ SKILL.md SKILL.md 內容請使用下一頁的 metadata、description 與執行步驟。 不要自行補充不存在的功能或額外檔案。 建立完成後，請將資料夾壓縮成 event-promo.zip 並提供下載連結。

重點：實際操作時，要把下一頁整段 SKILL.md 內容貼進同一個 Prompt；不要只叫 AI「建立 SKILL.md」。

SKILL.md 04 / 07
Skill 內容

把固定流程寫進 SKILL.md

--- name: event-promo description: 當使用者提供活動企劃內容，需要產出 Instagram 貼文、Email 通知、系辦公告三種宣傳文字時使用。每種版本須包含活動亮點、適合對象、報名呼籲。 --- # event-promo ## 執行步驟 1. 閱讀使用者提供的活動企劃內容 2. 產出 Instagram 貼文：語氣活潑，150 字以內 3. 產出 Email 通知：語氣正式清楚，250 字以內 4. 產出系辦公告：語氣簡潔，條列式 5. 每種版本皆須包含：活動亮點、適合對象、報名呼籲
UPLOAD TO CLAUDE 05 / 07
如何新增 Skill

在 claude.ai 上傳 Skill

前置確認

Settings → Capabilities，確認 Code execution and file creation 已開啟。

否則 Skill 可能無法建立檔案或正常執行。

ZIP 結構

上傳的 zip 內要有子資料夾：

event-promo/ SKILL.md
  1. 左側 sidebar 點選 Customize 圖示
  2. 進入 Skills，點右上角 +
  3. 選擇 Create skill → Upload a skill
  4. 在 Upload skill 視窗拖放或點選上傳 event-promo.zip
  5. 上傳完成後即刻生效

自動觸發：直接貼企劃案

以下是我們系上的期末成果展企劃案，請幫我產出三種宣傳文字： 【企劃案內容】 活動名稱：2025 資管系期末成果展 時間：6 月 20 日 14:00-17:00 地點：電腦教室 B201 內容：學生專題展示、業界評審回饋、最佳專題頒獎 對象：在校師生、系友、對資訊科技有興趣的高中生 報名：表單連結 forms.gle/xxx

Claude 讀到「產出三種宣傳文字」加上企劃內容，會比對 description 並載入 event-promo Skill。
